# 🚀 AI Ads Optimizer

AI-powered marketing analytics platform designed to analyze campaign performance, identify optimization opportunities, and generate strategic recommendations to improve advertising ROI.

## 🌐 Live Demo
https://ai-ads-optimizer.streamlit.app/

## 📂 GitHub Repository
https://github.com/K1-jen/ai-ads-optimizer

## 🎯 Business Problem

Marketing teams often struggle to:
- Detect underperforming campaigns quickly
- Optimize ad spend allocation
- Translate raw campaign data into strategic actions
- Generate scalable performance insights

This platform automates campaign analysis and delivers AI-generated optimization recommendations for smarter decision-making.

## ✨ Features

- 📊 Campaign performance analysis
- 🤖 AI-generated recommendations
- 📈 ROI and CTR optimization insights
- 🔍 Underperforming ad detection
- 🧠 Predictive analytics
- 📉 Budget allocation recommendations
- ⚡ Streamlit interactive dashboard

## 🏠Architecture
